# TikTok LIVE API - Directory Submission Checklist

Product: TikTok LIVE API
Base URL: https://api.tik.tools
Docs and API key: https://tik.tools/pricing (7-day free evaluation)
One-liner: Real-time TikTok LIVE data - liveness detection, room and creator info, in-room and regional rankings, gift catalogs, and live discovery. 7-day free evaluation, paid tiers for full leaderboards and agency recruiting feeds.

Assets in this folder to attach where relevant:
- gpt-actions-schema.json (OpenAPI 3.1 spec)
- postman-collection.json (Postman Collection v2.1)
- custom-gpt-instructions.md (Custom GPT config)

---

## Submission targets

- Postman Public API Network - https://www.postman.com/explore - publish the workspace containing postman-collection.json, then submit it for the public network. Requires a free Postman account and a public workspace.

- PublicAPIs.dev - https://publicapis.dev/ (source repo https://github.com/marcuswhybrow/public-apis) - open a PR adding the API entry (name, description, auth=apiKey, HTTPS=yes, CORS, category). Requires a GitHub account.

- APIs.guru - https://github.com/APIs-guru/openapi-directory - open a PR adding gpt-actions-schema.json under APIs/tik.tools with a version folder. Requires a GitHub account and a valid OpenAPI file.

- ProgrammableWeb-alternatives (RapidAPI Hub) - https://rapidapi.com/ - list the API on RapidAPI Hub as the leading ProgrammableWeb replacement. Requires a RapidAPI provider account; upload the OpenAPI spec.

- Product Hunt - https://www.producthunt.com/posts/new - submit as a new product with tagline, gallery images, and the tik.tools/pricing link. Requires a Product Hunt account; schedule a launch day.

- AlternativeTo - https://alternativeto.net/manage-app/ - add the product as a developer-tools / API listing with description and link. Requires a free AlternativeTo account.

- awesome-tiktok (GitHub) - https://github.com/drawrowfly/awesome-tiktok - open a PR adding a bullet under the APIs or tools section linking to tik.tools. Requires a GitHub account and following the list format.

- public-apis (GitHub) - https://github.com/public-apis/public-apis - open a PR adding the entry under a fitting category (for example Social) with Auth=apiKey, HTTPS=Yes, CORS value. Requires a GitHub account; keep the table column format exact and alphabetical.
